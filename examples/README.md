# Worked examples

Four tasks, each with a filled-in run card, a prompt you could send, and the criteria for
accepting the result. The repositories, file paths and teams are fictional.

| Example | Shows | Templates used |
| --- | --- | --- |
| [1. Routine coding task](01-routine-coding-task.md) | Stepping down a tier for known-path work | Run card, quick prompt |
| [2. Complex architectural implementation](02-architectural-implementation.md) | Propose first, then a change with checkpoints on a risky surface | Run card, execution prompt |
| [3. Multi-agent repository workflow](03-multi-agent-workflow.md) | A planned fan-out with a pilot, disjoint writers and a verify stage | Run card, workflow plan, execution prompt |
| [4. Independent security review](04-independent-security-review.md) | A fresh, read-only reviewer working from criteria | Run card, review brief |

## Reading the examples

- **Model names are dated.** The run cards name the models that filled each tier when
  [model data](../docs/model-data.md) was last verified. Read the tier first; substitute what
  your environment offers.
- **The configurations are recommendations.** Each example ends with what would change the
  recommendation. None of them has been benchmarked, and the commands in the checks belong to
  fictional projects.
- **The prompts are complete.** Each can be sent as written; where one points at a file, the
  example says what that file contains.
